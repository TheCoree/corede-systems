# corede Systems — frontend

Next.js 16 (App Router, Cache Components + Partial Prefetching), TypeScript, Tailwind CSS 4.

```bash
pnpm install
pnpm dev        # http://localhost:3000, /api/* проксируется на API_URL (по умолчанию http://127.0.0.1:8000)
pnpm build      # standalone-сборка: node .next/standalone/server.js
```

Общее описание, архитектура и деплой — в [README в корне репозитория](../README.md).
